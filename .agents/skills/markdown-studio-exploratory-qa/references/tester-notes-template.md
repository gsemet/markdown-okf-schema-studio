## Finding Drafts

For each finding, include the complete use case, preconditions, exact reproducible interaction,
expected and observed behavior, user impact, category, severity, confidence, and evidence links.
Record disagreements with other testers without forcing consensus.

## Incomplete Goal or Blocker

for steps that were not visibly completed.
