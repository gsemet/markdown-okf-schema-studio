## Table directives render as ordinary tables

### Normative behavior

When a document uses list, caption or CSV table directives, the Studio SHALL show them as ordinary tables.

### Preserved stakeholder intent

As a writer, I want all table directive forms to look like tables so that I can review data without building.

### Rationale and constraints

- Content stays as authored in the source.
