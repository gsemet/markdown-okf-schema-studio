## Read numbered, emphasized and captioned listings

### Normative behavior

When a writer previews a MyST code directive with line numbers, emphasized lines, a file name or a caption, the Studio SHALL show them with the code.

### Preserved stakeholder intent

## User Need

Authors need listings that point readers at specific lines and name their source.

### Rationale and constraints

- Applies to MyST code directives; plain fences are covered by the highlighted code samples need.
