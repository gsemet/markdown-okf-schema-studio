## Read text in any script and direction

### Normative behavior

When a document contains CJK, right-to-left text or long unbreakable words, the Studio SHALL display it readably inside the preview column.

### Preserved stakeholder intent

Writers need to read documents in any script and direction without horizontal scrolling.

### Rationale and constraints

- Covers Japanese, Chinese, Korean, Hebrew and Arabic text and long URLs.
