# Markdown OKF-Schema Studio User Guide

The [project README](../../README.md) shows what Studio does. These pages hold the details.

- [Install and Open Studio](open-studio.md): Marketplace install, Open With, preview to the side.
- [Features and Inline Editing](editing.md): MyST rendering, block editing, the edition palette,
  block selection, rich paste.
- [Floating Toolbar](toolbar.md): the three rows of buttons and the collapse chevron.
- [Slash Menu](slash-menu.md): the `/` command menu in a block text box.
- [Preview Themes and Motion](themes-and-motion.md): Dark, White, Cream, and the short animations.
- [Wide Tables and Figures](wide-tables.md): the Auto width mode.
- [PlantUML Diagrams](plantuml.md): the built-in engine, includes and the optional JAR.
- [Review Comments](review-comments.md): comment threads stored next to the document.
- [Open Knowledge Format](okf.md): schema-aware properties and linked-file annotations.
- [Sphinx Projects](sphinx.md): the `myst_enable_extensions` check against `conf.py`.
- [Settings](settings.md): every setting by category.
- [Comparison](comparison.md): what we found, and did not find, in other Markdown tools.
