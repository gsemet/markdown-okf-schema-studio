# Wide Tables and Figures

With the Width button on Auto, the text stays in a comfortable narrow column while a table or a
figure wider than the column breaks out of it, takes the width it needs (up to the space left of
the table of contents) and is centred. Narrower tables and figures are centred in the column.
In Auto width a table (also one inside a figure or a list-table) is measured through its inner
table. Short columns (numbers, names, short code names) stay on one line; prose columns wrap but keep
about 24 characters of width. The table stays in the text column when those minimums fit, and
breaks out (up to the space left of the table of contents, centred) when they do not, or when a
cell holds content that cannot shrink (a code block, a long unbroken word). Margin and Full width
are unchanged: the table scrolls sideways. A table with merged cells, a nested table or no
rows keeps the older natural-width rule and can still break out.
The capture uses the cream theme.
