# Announcement thread for 1.12.0

## 1/

I had the diff of a Markdown file open in VS Code and wanted to see how the page reads, and I had to leave the diff to find out. In 1.12 the side preview opens right next to the text diff, a green change bar tells you which lines changed, and a click on it opens the diff of that block. Blank lines inside lists and quotes are now easy to reach, and a dropdown shows its content.

Image: change-bar-tooltip.png
