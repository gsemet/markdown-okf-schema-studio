# Announcement thread for 1.5.0

## 1/

I open a plan an agent left in a scratch folder, and Studio used to refuse to edit it because the
folder was not trusted. Studio 1.5 lets me edit any document, in Restricted Mode too. A comment on a
sentence that wraps over several lines now gets its highlight, and Escape closes the comment editor
wherever I am.
