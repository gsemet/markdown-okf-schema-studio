# Announcement thread for 1.9.1

## 1/

Small one. When I shipped 1.9.0, VS Code users had it at once, but the copy on Open VSX, the
registry behind VSCodium and Cursor, only arrived after I ran the publication a second time by
hand. 1.9.1 changes nothing in the extension; it is the first release that reaches both registries
in the same run, so the update shows up in every editor at the same time.
