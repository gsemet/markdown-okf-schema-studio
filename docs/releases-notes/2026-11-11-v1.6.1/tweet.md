# Announcement thread for 1.6.1

## 1/

I spent a long session editing tables in Studio the way I really use it: with the page beside the
source, undoing a lot, and tables written by an agent with `:--` delimiters. A few things got in the
way. In Studio 1.6.1 every table cell opens on a click, undo and Revert File put the table back as
the file holds it, and the cell editor fits a narrow pane.
