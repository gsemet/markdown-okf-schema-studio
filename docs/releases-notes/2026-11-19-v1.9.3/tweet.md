# Announcement thread for 1.9.3

## 1/

1.9.2 made edit mode lighter on long documents, but closing a block editor still took a beat
before the page showed my change. The preview was waiting for the typing pause, which grows with
the document. 1.9.3 renders a committed edit at once: about 2 seconds became under half a second
on my longest chapter.
