# Announcement thread for 1.9.2

## 1/

I keep long design notes with a dozen tables in them, and an agent edits them as much as I do.
In edit mode that page had become sticky: hovering the toolbar or opening a block took a beat.
The cause was the page being laid out again for every table and every row handle. 1.9.2 does
that work once, so editing a big document feels like editing a small one.

## 2/

The details are in the release notes:
https://github.com/gsemet/markdown-okf-schema-studio/releases/tag/v1.9.2
