# Announcement thread for 1.6.0

## 1/

I was asking an agent for a short design note and it gave me a small diagram as SVG. Studio used to
show it as code, so I had to export an image just to see it. Studio 1.6 draws the SVG in the page, in
the colours of the theme. A front matter field can now be shown in the text with `= this.title`, and
a wide table no longer shrinks while I edit one of its cells.

Image: svg-pictures.png
