# List-table row handles

A list-table with a title and one header row. In edit mode each body row shows a handle.

```{list-table} Release steps
:header-rows: 1
:widths: 30 70

* - Step
  - Notes
* - Draft the proposal
  - Written with the **team** and `reviewed` twice
* - Review the proposal
  - Needs two approvals
* - Publish the release
  - Tagged and announced
```

A list-table with two header rows and no title keeps both header rows fixed:

```{list-table}
:header-rows: 2

* - Step
  - Owner
* - name
  - person
* - Archive
  - Dev
* - Announce
  - Cleo
```
