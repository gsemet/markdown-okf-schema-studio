# FullCycle: an SDLC Opinionated Workflow Skills

A personal and opinionated workflow from Jira issue to resolution,
using the skills provided from other Compendium plugins.

You need to enable these plugins:

- `compendium-jira-confluence`:
  - `jira-skill`.
  - `derive-jira-issue-to-change-request`
- `compendium-gitlab`:
  - `glab`
  - `monitor-gitlab-ci`
  - `ship-gitlab-mergerequest`
- `compendium-sdlc`:
  - `grill-me`
  - `wayfinder`
- `compendium-generic`:
  - `get-session-costs`
  - `record-findings`
  - `rubber-duck`
- `compendium-harness`:
  - `adr-creator`
  - `doc-gardening`
  - `agents-md-creator`
  - `dependency-gardening`
  - `guideline-creator`
  - `ubiquitous-language`
  - `what-can-i-improve`
